## Densitometry state (`/experimental/densitometry`, method `hiveblot.densitometry` v0.3.0)

What a researcher can do now, verified in the local browser on a synthetic upload and on
reviewed record 4455 (STAT3 panel, `page_005_cand_0034.png`):

1. load a HiveBlot crop by record id (reviewed or live tier) or upload a PNG/JPEG;
2. drag a box around one blot strip; the box is drawn immediately;
3. seed N lane dividers from a lane count, then add / remove / drag dividers; label lanes;
4. Measure → the exact returned geometry (region, band row, every lane) is overlaid on the image,
   coloured by per-lane quality;
5. per lane: raw / background / background-corrected integrated darkness, relative to the
   strongest lane **as a min–max range** from the perturbation envelope, clipped-core fraction,
   quality state and reasons;
6. a quality card: *Valid within-image relative measurement* / *Warning* / *Quantification
   refused* with the reasons; refused lanes and refused strips carry `relative: null` and the UI
   shows no number or bar for them;
7. Export JSON (full response incl. method name, version, every threshold, region, lane bounds,
   band row, image sha256), CSV, and an overlay PNG (image + returned geometry coloured by
   quality + method footer).

Gates (all thresholds are reported in `method.params` of every response):

| gate | behaviour |
|---|---|
| band-core clipping (pixels within 8 DN of the floor, core = ≥50% of lane peak) | ≥2% warning · ≥10% lane refused; if that lane is the reference the whole strip is refused |
| no signal above background (robust SNR < 3 on the off-band residual) | lane flagged; whole strip refused when no lane has signal |
| invalid geometry (reversed / overlapping / outside-region / <3 px lanes, tiny region, label count mismatch) | HTTP 400, nothing measured |
| perturbation envelope (±5% median lane width, ±10% row height, min 2 px; 13 runs) | per-lane min/median/max; envelope width >0.25 → warning |
| reference lane changes under perturbation | near tie (alternative was within 25% of top) → warning, values kept, tie lanes listed; clearly weaker alternative → refused |
| polarity | decided on the whole image, not the box |
| background | rolling-ball opening with a radius from the whole image, not the box (a tight box otherwise absorbs the band into background), then a per-lane **flank baseline**: median of membrane rows one band-height above and below the band (the lower of the two), so white space or a neighbouring strip elsewhere in the box does not count as signal; noise = MAD of that flank |
| no flank rows | box too tight to see membrane around the band → warning, opening-only background, SNR not estimated |
| multi-strip box | box containing ≥2 band rows → at least a warning; the UI's row buttons re-box the chosen strip (its height plus a margin) and re-measure |
| band row | detected inside the box (`row_index` among detected rows) or researcher-chosen `band_row` = the full box height; validated against the box |
| weak lane | mean corrected signal within 3σ of the off-band residual → per-lane "weak" flag, value kept; whole strip refused when every lane is weak |
| printed-text row | flagged in `rows_text_like`; warning when the measured row looks like labels |

Diagnostics that are NOT the product path and say so in the response: lane count (equal-width
slices) and auto lane detection (`lane_mode` ≠ `explicit`).

Validation done:
- `research/experiments/D2_clip_threshold_study.md` — synthetic known ratios: unclipped ratio error
  ≤1.8% (v0.3 flank baseline; was 7.4% in v0.2); the refuse gate fires at ~18% clipped core while the
  error is still ~1%, before the regime where it climbs to 9–95%; JPEG floor smearing (q 60–95) does
  not hide clipping; second adversarial pass: big-image tight box, x-gradient, light-on-dark, JPEG q70,
  RGB, wide lanes all within 0.01 of truth; tight vs re-boxed real strip agree within 0.04.
- `research/experiments/D5_real_crops_refusal.md` — 21 reviewed crops with auto geometry (whole crop,
  so every box holds several strips): 21/21 have a row clipped past the gate, 81/112 rows refused,
  31 warning, 0 ok. Refusing is the feature on published figures; a valid reading needs a
  single-strip box (see the real-crop test checks).

Known scientific limitations (say these out loud at UCSF):
- pixel darkness of a published figure, uncalibrated, no units, one image only;
- not protein amount; not loading-control normalized; not comparable across images/exposures;
- thresholds are v0.2 defaults justified on synthetic fixtures, to be re-derived on a real dilution
  series (ticket D-7); no author-value comparison yet;
- nothing is stored; the reserved intensity columns on Evidence Records stay NULL.
